# Controle Financeiro

Aplicativo desenvolvido em Flutter para gerenciamento de finanças pessoais, utilizando SQLite como banco de dados local e Floor como camada de persistência.

O sistema permite cadastrar, listar, atualizar e remover lançamentos financeiros, classificando-os por categorias e tipo (receita ou despesa). Os dados são armazenados localmente no dispositivo e exibidos em uma interface reativa através do StreamBuilder.

## Funcionalidades

* Cadastro de categorias
* Cadastro de receitas e despesas
* Listagem automática dos lançamentos
* Exclusão de lançamentos
* Filtro por categoria
* Filtro por tipo (receita/despesa)
* Cálculo de saldo total utilizando consultas SQL
* Persistência local com SQLite e Floor

## Tecnologias Utilizadas

* Flutter
* Dart
* SQLite
* Floor ORM
* StreamBuilder
